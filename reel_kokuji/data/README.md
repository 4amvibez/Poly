# Data

- `east_asia_land.json` — land polygons for the sea chart in scene 2, cropped to lon 110–148°E, lat 22–48°N from
  **Natural Earth 1:10m Land** (public domain, naturalearthdata.com, via github.com/nvkelso/natural-earth-vector).
  `r5art.east_asia_chart()` projects them (Mercator, 80 px per degree) and paints the chart.

Fonts in `../fonts/` are subsets of Shippori Mincho B1 and Yuji Syuku (SIL Open Font License) fetched from Google Fonts
for exactly the characters in `fonts/charset.txt`.
